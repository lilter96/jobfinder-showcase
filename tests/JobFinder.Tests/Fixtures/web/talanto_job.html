Job description

Ищем Backend .NET / C# Developer (AI-first) для разработки бэкенд-сервисов банковского приложения.

Задачи:

  • Разработка и развитие бэкенд-сервисов на .NET 8
  • Проектирование и реализация API для мобильного приложения и веба
  • Активное использование AI-инструментов для генерации кода, тестов, документации и миграций
  • Работа с финансовой логикой: транзакции, лимиты, комиссии, идемпотентность операций
  • Интеграции с платёжными и банковскими системами
  • Участие в проектировании архитектуры и код-ревью

Требования:

  • Опыт разработки: от 4 лет коммерческой разработки на C# / .NET
  • Уверенный опыт с .NET Core / .NET 6–8+
  • Стек: Core, Web API, Entity Framework Core, микросервисы, REST/gRPC
  • Очереди: RabbitMQ / Kafka
  • Уверенный SQL, Docker
  • AI-компетенции: практика с Claude Code / Copilot, умение декомпозировать задачи для AI и критически ревьюить сгенерированный код
  • Понимание безопасности: OAuth2/OIDC, JWT, шифрование данных, OWASP Top 10
  • Английский B2+

Плюсы:

  • Коммерческий опыт в финтехе / банкинге / платежах
  • PCI DSS, ISO 8583 / ISO 20022, интеграции с процессингом и эквайрингом
  • MCP, автоматизация CI/CD и генерация тестов с помощью AI

Условия:

  • Полностью удалённая работа (вне РФ), гибкий график
  • Оплата в USD/USDT
  • Минимум бюрократии, работа в международной команде
